# ReconForge roadmap

The roadmap is ordered around researcher value and precision, not the number of integrated tools.

- [x] Hypothesis/evidence model

- [x] SQLite storage boundary
- [x] Tooling strategy and adapter contract

## Performance objective

We will not claim a universal vulnerability success rate. Instead, every release should report measurable performance on a stable benchmark and track:

- top-N investigation precision
- false-positive rate
- duplicate rate
- N/A rate
- mean time to useful hypothesis
- percentage of queue items accepted by the researcher as worth manual investigation
